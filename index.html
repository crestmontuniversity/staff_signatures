Crestmont University email signatures

Find your name, copy your signature, paste it into Outlook.

    Choose your name from the list to see your signature.

    How to add it to Outlook

    1. Click Copy signature above.
    2. Outlook on the web or new Outlook: Settings (gear) → Accounts → Signatures → New signature.
      Classic Outlook: File → Options → Mail → Signatures → New.
    3. Click in the signature box and paste (Ctrl+V). Remove any old signature first.
    4. Set it as the default for new messages and replies, then Save.

    Wrong photo, phone number or title? Tell IT and it will be fixed here, then copy it again.
